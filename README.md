# CIS4014 Group 4 Interactive Visualisation

This repository contains the coursework materials and web application for the
CIS4014 Interactive Visualisation project. The project uses coffee shop sales
data and includes the source data, cleaned data, design documentation,
development records, chart work, prototypes, and the web application.

## Repository Contents

| Directory | Purpose |
| --- | --- |
| `data/` | Raw, cleaned, and processed project datasets. |
| `charts/` | Individual chart work organised by group member. |
| `prototypes/` | Early chart and interface prototypes organised by group member. |
| `documentation/data cleaning/` | Data-cleaning documentation. |
| `documentation/design/` | Design requirements and visualisation rationale. |
| `documentation/meetings/` | Project meeting minutes. |
| `documentation/scrum/` | Product backlog, sprint records, burndown charts, and retrospectives. |
| `documentation/testing/` | Testing and bug-fixing documentation. |
| `web/` | Browser-based interactive visualisation, including `index.html`, CSS, and JavaScript assets. |

## Running the Web App

The current web app is a static site. Open [`web/index.html`](web/index.html)
directly in a browser, or serve the repository with any local static file
server while development continues.

The published version is available at [The Roast Report](https://inkymello.github.io/The-Roast-Report---The-Morning-Rush/).
