# CIS4014 Group 4 Interactive Visualisation

Repository structure for the Interactive Visualisation project.

```text
data/                 Source and processed datasets
charts/member1/       Member 1 charts
charts/member2/       Member 2 charts
charts/member3/       Member 3 charts
prototypes/           Chart prototype images
documentation/scrum/  Scrum planning and sprint records
documentation/meetings/  Meeting records
documentation/design/    Requirements and chart rationale
web/                  Interactive visualisation application
```

The empty directories are retained with `.gitkeep` files until their project
assets are added.
